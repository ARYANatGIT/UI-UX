2. DETAILED EXPLANATION OF IMPLEMENTED TECHNIQUES
----------------------------------------------------------------------------------------------------

A. Static HTML Prerendering for Search Crawlers
Standard Single Page Applications (SPAs) deliver an empty shell (<div id="root"></div>), which fails
with crawlers that do not execute JavaScript. RAAHI utilizes a custom build-time static prerendering
script (scripts/prerender.js) that populates physical index.html files inside route subdirectories:
- dist/index.html (Homepage)
- dist/explore/index.html (Destination Hub)
- dist/guides/index.html (Travel Journal Hub)
- dist/guides/three-days-in-jaipur/index.html (Jaipur Article)
- dist/guides/munnar-travel-guide/index.html (Munnar Article)
- dist/guides/weekend-in-rishikesh/index.html (Rishikesh Article)
- dist/plan/index.html (Itinerary Tool)
- dist/404.html (Not Found Page)
This ensures search crawlers receive complete headings, copy, and structured data on initial fetch.

B. Title Tags & Meta Descriptions
Every route has a unique, intent-focused title and meta description:
- Home: "Raahi — Discover Beautiful Places to Visit in India | Travel Discovery & Planning" (81 chars)
- Explore: "Explore Indian Destinations by Region and Travel Style | Raahi" (62 chars)
- Guides: "India Travel Guides and Itineraries | Raahi" (43 chars)
- Jaipur: "Three Days in Jaipur: Beyond the Royal Pink Facades | Raahi Travel Journal" (74 chars)
- Munnar: "The Slow Guide to Munnar: Tea Forests & Shola Trails | Raahi Travel Journal" (75 chars)
- Rishikesh: "A Mindful Weekend in Rishikesh: River, Ridge & Reflection | Raahi Travel Journal" (80 chars)
- Plan: "Plan Your India Trip | Raahi Itinerary Builder" (46 chars)
- 404: "Page Not Found (404) | Raahi — Discover India Differently" (57 chars)

C. Heading Hierarchy
Strict enforcement of exactly one <h1> per page. Major thematic sections use <h2> with anchor IDs
(#day-1-royal-foundations, #cultural-etiquette, etc.), while sub-points use <h3>. This establishes
a logical semantic outline for search engine ranking algorithms.

D. Image SEO & Layout Shift Prevention
- Informative images contain descriptive, non-generic alt text.
- Explicit CSS aspect-ratios (16/10 for cards, 16/9 for hero images) prevent layout shifts (CLS).
- Above-the-fold hero images use fetchPriority="high" to optimize Largest Contentful Paint (LCP).
- Offscreen images use loading="lazy".

E. Structured Data (Schema.org JSON-LD)
Machine-readable JSON-LD schemas are embedded directly in static HTML and updated on client transitions:
- WebSite schema with SearchAction query input on Homepage
- CollectionPage with ItemList on Explore Hub
- BlogPosting schema with author, headline, datePublished, publisher on Guide articles
- WebApplication schema on Trip Planner

F. Technical SEO Assets
- robots.txt: Specifies crawler permissions, disallows /api/ and /admin/, points to sitemap.
- sitemap.xml: Declares canonical URLs for all indexable pages with lastmod and priorities.
- 404.html: Custom branded recovery page preventing soft-404 errors.
